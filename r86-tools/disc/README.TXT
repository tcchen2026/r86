r86 tools
=========

R86TOOL\R86-TOOL.EXE - Display modes, installer and absolute pointer helper.
See R86TOOL\README.TXT for usage; source: r86-tools/r86-tool.c
in the r86 repository.

VMDISP9X\ - MIT-licensed VMDisp9x 2D display driver for Windows 95/98/Me.
Update the adapter from VMDISP9X\vmdisp9x.inf; r86 uses QEMU STD VGA.
r86 changes one file: qemumini.drv accepts modes from 320x170 instead of
640x480 (two constants in FixModeInfo). Original license.txt, readme.txt
and version.txt are in the same folder.

This is a data CD, not a bootable installation disc.
